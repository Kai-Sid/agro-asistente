# Protocolo de usabilidad PMV3

Estado: **pendiente de ejecución con participantes**. Completar esta hoja con observaciones reales; no usar datos inventados.

## Objetivo

Comprobar que una persona con experiencia básica en agricultura puede registrarse, iniciar sesión, crear o seleccionar su contexto y enviar una consulta desde computadora y teléfono, entendiendo los mensajes cuando comete un error.

## Tareas

1. Crear una cuenta de agricultor con correo y contraseña válidos.
2. Iniciar sesión con esa cuenta.
3. Crear una parcela/contexto e indicar cultivo y región.
4. Seleccionar el contexto si todavía no está activo.
5. Enviar una pregunta relacionada con el cultivo y explicar con sus palabras la respuesta y las evidencias.
6. Repetir el flujo principal en pantalla móvil.
7. Recuperarse de un error inducido por el facilitador (por ejemplo, campo obligatorio vacío o credenciales incorrectas).
